1.  Search for the journal name. 
2.  If it appears, click on it: this will apply a filter for the works whose primary location is in the selected.journal. You can browse through this results set to see the journal’s works.
3.  If you do not find your journal searching by name, you can try to search for the journal’s ISSN. Type the ISSN into the search bar, and the journal should appear. 

If this doesn’t work, get in touch with us: [https://openalex.org/support](https://openalex.org/support)
