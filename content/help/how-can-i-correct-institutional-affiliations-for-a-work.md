If you see that an institution is incorrectly attributed to a work, you can using the [works-magnet tool](https://works-magnet.esr.gouv.fr/) to fix that affiliation. We have made a [YouTube video](https://www.youtube.com/watch?v=OIFHhz2OQPg&ab_channel=OurResearch) that shows you how to submit a curation request. You should be able to see the changes in our data within 2-3 weeks!

If you are wondering how OpenAlex attributes works to an institution, please check out the [affiliations documentation](/data/raw-affiliation-strings/).
