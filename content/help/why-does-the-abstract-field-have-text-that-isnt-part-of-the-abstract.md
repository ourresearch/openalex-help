We get abstract metadata from diverse sources and sometimes we have to source it from fulltext articles using text mining techniques. Our processes usually do a great job collecting just the abstract. But sometimes, they pull in additional information after the end of an abstract.

If you come across an error, you can submit a correction to the abstract text using this form: [Fix an OpenAlex work record](https://docs.google.com/forms/d/e/1FAIpQLScUcNZdqOBFxVJ0oihjeHFilm9IqqWKQY4WDmmqgxUNGr3R1g/viewform)

If you find a broader issue that affects more than a few individual articles, let us know at [support@openalex.org](mailto:support@openalex.org) so that we can investigate and deploy a fix.
