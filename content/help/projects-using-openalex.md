We're excited about the growing number of projects using OpenAlex and think it's important to profile them. This page is new so bear with us as we start adding more projects to the list. If there is one in particular you think we should add, shoot us a note at: [support@openalex.org](mailto:support@openalex.org) 

## OpenAlex Libraries

-   The [**openalexr**](https://cran.r-project.org/web/packages/openalexR/index.html) R package collects and analyzes OpenAlex data in R ([more info](https://docs.ropensci.org/openalexR/))
-   The [**PyAlex**](https://github.com/J535D165/pyalex) Python library collects and analyzes OpenAlex data in Python ([more info](https://zenodo.org/records/13373916))

## Open source tools

-   The **[works-magnet](https://works-magnet.esr.gouv.fr/)** helps users identifies and correct errors in OpenAlex affiliation matching ([tutorial](https://www.youtube.com/watch?v=OIFHhz2OQPg))
-   The **[Open Research Converter](https://orc-demo.gesis.org/)** resolving DOIs to OpenAlex works IDs at scale ([more info](https://github.com/jhculb/Open-Research-Converter))
-   [**VOSViewer**](https://www.vosviewer.com/) supports copy and pasting OpenAlex URLs or API calls to freely analyze and visualize bibliometric networks ([video tutorial](https://www.youtube.com/watch?v=ZNyi29IER90))
-   **[PubAnalyser](https://pubanalyser.streamlit.app/)** tracks costs of Publications by Publisher ([more info](https://github.com/dbann/pubanalyser))

## Dashboards

-   The **[CWTS dashboard](https://app.powerbi.com/view?r=eyJrIjoiZmI0YzljYjYtYWZlNy00YzUzLWE1YjYtYjdkNmYwMDUzNjFmIiwidCI6ImNhMmE3Zjc2LWRiZDctNGVjMC05MTA4LTZiM2Q1MjRmYjdjOCIsImMiOjh9)** compares rankings based on Web of Science vs OpenAlex data ([more info](https://www.leidenmadtrics.nl/articles/launch-of-the-cwts-leiden-ranking-open-edition-2024))
-   The [**Curtin Open Knowledge Initiative (COKI) dashboard**](https://open.coki.ac/) analyzes global open access trends ([more info](https://openknowledge.community/))
-   The **[Ethiopia National Evidence Portal](https://ethiopia.opendeved.net/en-US/lib)**

## Discovery tools

-   [**SemOpenAlex**](https://semopenalex.org/resource/semopenalex:UniversalSearch) supports semantic search of OpenAlex data
-   [**oa.mg**](https://oa.mg/) facilitates search and discovery of open access publications
