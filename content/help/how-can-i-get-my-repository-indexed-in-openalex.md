Currently, OpenAlex doesn't mint new works for institutional repositories. Instead, when we get information about a new publication we look through institutional repositories to see if there is an Open Access version of that work that we can link to. 

If you want to check and see if your repository is one that we check for open access versions of publications or add it to our list, you can do that here: [Data sources | Unpaywall](https://unpaywall.org/sources)

In Spring 2025, we'll be starting to directly ingest institutional repositories to mint new works. If you want to make sure your repository gets added to that list, you can let us know here: [https://forms.gle/LMmjdKw9HZJooxVT8](https://forms.gle/LMmjdKw9HZJooxVT8)
