First, make sure your repository is on our harvest list. When OpenAlex learns about a new publication, it looks through the repositories on this list for an Open Access version of that work to link to. You can check whether your repository is on the list — or add it — here: [Data sources | Unpaywall](https://unpaywall.org/sources)

Beyond that, OpenAlex now also mints new works directly from repository records. Repository records that don't match an already-known publication become works in the **expansion corpus** (added in the November 2025 Walden update), which API users can include with `include_xpac=true`. If you'd like your repository considered for direct indexing, register it here: [Registering Repositories with OpenAlex](https://forms.gle/LMmjdKw9HZJooxVT8)

For the details of how harvesting and matching work — and how your repository's metadata can make matching more reliable — see [Repository records](/docs/repository-records/) in the Docs.
