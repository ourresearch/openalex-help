Recent updates and changes to the OpenAlex API.

## 2026

### February 13, 2026

**API keys required** — All API requests now require an API key. You can get your free key at [openalex.org/settings/api](https://openalex.org/settings/api).

### February 4, 2026

**API keys recommended** — API keys are now recommended for all requests. Starting February 13, they become required.

For older updates and announcements, see the [OpenAlex User Group](https://groups.google.com/g/openalex-users).
