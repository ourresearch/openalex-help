We pull APC paid data for publications directly from [OpenAPC](https://openapc.net/). But when that information is not available, we estimate it from APC list prices for the journal, which we get from DOAJ and additional manual curation.

You can read more about assumptions when estimating APC spend here: [Open Access (OA) – OpenAlex](https://help.openalex.org/hc/en-us/articles/24347035046295-Open-Access-OA)
