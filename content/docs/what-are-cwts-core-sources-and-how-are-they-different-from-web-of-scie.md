The [CWTS Core Source filter](https://openalex.org/works?page=1&filter=primary_location.source.is_core%3Atrue) in OpenAlex can be used to return only publications from sources that are included in the [Centre for Science and Technology Studies](https://www.cwts.nl/) (CWTS) list of [Core sources](https://zenodo.org/records/13879982). CWTS designed this list to subset the list of sources from OpenAlex included in their [Leiden Ranking Open Edition](https://open.leidenranking.com/). By including this filter in OpenAlex, users can further explore the data underlying those rankings or negate the filter to understand what is being excluded from those rankings.

This is not related to the [Web of Science Core Collection](https://webofscience.help.clarivate.com/Content/wos-core-collection/wos-core-collection.htm), which is a selective list of journals indexed in Web of Science that is maintained by [Clarivate.](https://clarivate.com/) 

More information on the CWTS Core sources can be found here: [Core sources and core publications in OpenAlex](https://zenodo.org/records/13879982)
